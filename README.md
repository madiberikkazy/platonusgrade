# BAGA — Platonus баға калькуляторы

Қазақша/орысша, mobile-first Platonus баға калькуляторы. Қосымша тәуелділіксіз статикалық сайт.

## Іске қосу

```bash
python3 -m http.server 4173 -d dist
```

Содан кейін `http://localhost:4173` адресін ашыңыз.

## Формула

- ТК — толтырылған сандық бағалардың орташа мәні. `н.п.` және `н.б.` орташаға кірмейді, `+` = 100, `−` = 0.
- Рейтинг — әдепкіде `ТК × 60% + РК × 40%`.
- Рұқсат рейтингі — `(Рейтинг 1 + Рейтинг 2) / 2`.
- Қорытынды — `Рұқсат рейтингі × 60% + Емтихан × 40%`.

Барлық салмақтар интерфейстегі «Формула баптаулары» бөлімінде өзгертіледі.
